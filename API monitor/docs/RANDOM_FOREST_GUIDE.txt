========================================
MANUAL UPGRADE (Alternative)
========================================

1. Install scikit-learn:
   > pip install scikit-learn==1.3.0

2. Backup old predictor:
   > copy ai_predictor.py ai_predictor_old.py

3. Replace with Random Forest version:
   > copy ai_predictor_rf.py ai_predictor.py

4. Train model:
   > python train_model.py

5. Restart:
   > START_HERE.bat

========================================
TRAINING THE MODEL
========================================

When to Train:
  - After upgrade
  - When adding new APIs
  - Weekly (for best results)
  - After major incidents

How to Train:
  > python train_model.py

What Happens:
  1. Collects data from all APIs
  2. Extracts 15 features per API
  3. Trains Random Forest (100 trees)
  4. Saves model to models/rf_model.pkl
  5. Shows training accuracy
  6. Shows feature importance

Training Requirements:
  - At least 1 monitored API
  - At least 10 data samples
  - MongoDB running
  - scikit-learn installed

FALLBACK BEHAVIOR
========================================

If scikit-learn not installed:
  → Falls back to statistical method
  → Shows warning message
  → Everything still works!

If model not trained:
  → Uses statistical method
  → Suggests training
  → No errors

If insufficient data:
  → Returns "Insufficient data"
  → Waits for more samples
  → Graceful handling
