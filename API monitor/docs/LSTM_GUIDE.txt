========================================
MODEL ARCHITECTURE
========================================

LSTM MODEL (Failure Prediction):
  Input: (20, 10) - 20 time steps, 10 features
  ├─ LSTM Layer 1: 64 units, return sequences
  ├─ Dropout: 0.2
  ├─ LSTM Layer 2: 32 units
  ├─ Dropout: 0.2
  ├─ Dense Layer: 16 units, ReLU
  └─ Output: 1 unit, Sigmoid (0-1 probability)
  
  Total Parameters: ~50,000
  Optimizer: Adam
  Loss: Binary Crossentropy
  Metrics: Accuracy, AUC

AUTOENCODER (Anomaly Detection):
  Input: (20, 10) - 20 time steps, 10 features
  
  Encoder:
  ├─ LSTM: 32 units, return sequences
  └─ LSTM: 16 units (compressed representation)
  
  Decoder:
  ├─ RepeatVector: 20 time steps
  ├─ LSTM: 16 units, return sequences
  ├─ LSTM: 32 units, return sequences
  └─ TimeDistributed Dense: 10 features
  
  Total Parameters: ~30,000
  Optimizer: Adam
  Loss: Mean Squared Error

========================================
10 TIME-SERIES FEATURES
========================================

For each time step (every check):
  1. is_up           → 1.0 if up, 0.0 if down
  2. total_latency   → Response time (seconds)
  3. dns_latency     → DNS lookup time
  4. tcp_latency     → TCP connection time
  5. tls_latency     → TLS handshake time
  6. server_latency  → Server processing time
  7. download_latency → Content download time
  8. status_code     → HTTP status (normalized)
  9. has_error       → 1.0 if error, 0.0 if not
  10. placeholder    → Reserved for future

Sequence Length: 20 time steps
Total Input: 20 × 10 = 200 values per prediction

========================================
HOW IT WORKS
========================================

FAILURE PREDICTION (LSTM):
  1. Collect last 20 API checks
  2. Extract 10 features per check
  3. Normalize features (StandardScaler)
  4. Feed into LSTM network
  5. LSTM analyzes temporal patterns
  6. Output: Probability of failure (0-1)
  7. Convert to risk score (0-100)

ANOMALY DETECTION (Autoencoder):
  1. Train on "normal" API behavior
  2. Learn to reconstruct normal patterns
  3. For new data, try to reconstruct
  4. Calculate reconstruction error
  5. High error = Anomaly detected
  6. Threshold: 95th percentile of training errors

========================================
TRAINING PROCESS
========================================

Data Collection:
  - Collects last 48 hours of data per API
  - Creates sequences of 20 time steps
  - Extracts features for each step
  - Labels: 1 if next check fails, 0 if succeeds

LSTM Training:
  - 80/20 train/validation split
  - 50 epochs (with early stopping)
  - Batch size: 32
  - Learning rate reduction on plateau
  - Best model saved automatically

Autoencoder Training:
  - Trains only on normal (non-failure) data
  - 80/20 train/validation split
  - 50 epochs (with early stopping)
  - Learns to reconstruct normal patterns
  - Calculates anomaly threshold (95th percentile)

Training Time:
  - 10 APIs: ~3-5 minutes
  - 50 APIs: ~8-12 minutes
  - 100 APIs: ~15-20 minutes
