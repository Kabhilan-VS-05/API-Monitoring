GITHUB PERSONAL ACCESS TOKEN
========================================

If GitHub asks for password when pushing:

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Name: "API Monitoring Project"
4. Expiration: 90 days (or custom)
5. Scopes: Check "repo" (full control)
6. Click "Generate token"
7. COPY THE TOKEN (you won't see it again!)
8. Use token as password when git asks


========================================
TROUBLESHOOTING
========================================

Error: "Permission denied"
--------------------------------------------
Solution: Use HTTPS URL instead of SSH
git remote set-url origin https://github.com/YOUR_USERNAME/ai-copilot-api-monitoring.git


Error: "Repository not found"
--------------------------------------------
Solution: Check if repository exists and URL is correct
git remote -v


Error: "Updates were rejected"
--------------------------------------------
Solution: Pull first, then push
git pull origin main --rebase
git push origin main


Error: "fatal: not a git repository"
--------------------------------------------
Solution: Initialize git
git init
