========================================
QUICK COMMANDS
========================================

Start Application:
  > START_HERE.bat

Run Tests:
  > RUN_TESTS.bat

Start Test API:
  > cd "running API"
  > python api_testing.py

Access Dashboards:
  Simple:   http://localhost:5000
  Advanced: http://localhost:5000/advanced_monitor
