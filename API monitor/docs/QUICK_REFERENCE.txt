┌────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                             │
└────────────────────────────────────────────────────────────────┘

MongoDB not connected:
  → net start MongoDB

Port 5000 in use:
  → Change port in app.py: app.run(port=5001)

GitHub sync fails:
  → Check GITHUB_TOKEN is set
  → Verify token has repo access

AI shows "Insufficient data":
  → Wait for 5+ monitoring checks
  → Check MongoDB has data

NumPy not found:
  → pip install numpy==1.24.3

┌────────────────────────────────────────────────────────────────┐
│ 🎯 COMMON WORKFLOWS                                            │
└────────────────────────────────────────────────────────────────┘

ADD NEW API:
  1. Click "Add New Monitor"
  2. Enter URL
  3. Choose frequency
  4. Add category (optional)
  5. Click "Add Monitor"

CHECK AI PREDICTION:
  1. Find monitor card
  2. Click "🤖 AI Insights"
  3. View risk score
  4. Read recommendations
  5. Close modal

SYNC GITHUB DATA:
  1. Click "⚙️ Settings"
  2. Enter repo details
  3. Click "Sync GitHub Data"
  4. Wait for success message
  5. Scroll to see data

CREATE INCIDENT:
  1. Click "⚙️ Settings"
  2. Scroll to "Create Incident"
  3. Fill in details
  4. Choose severity
  5. Click "Create Incident"
