========================================
AI FEATURES EXPLAINED:
========================================

1. FAILURE PREDICTION
   Analyzes:
   - Recent failure rate (last 100 checks)
   - Latency trends (increasing/decreasing)
   - Average latency (high = risky)
   - Error count (24 hours)
   - Recent code changes (commits)
   
   Calculates:
   - Risk score (0-100)
   - Confidence level (0-100%)
   - Will fail (true/false)
   
   Risk Levels:
   - 0-40: ✅ Low Risk (Safe)
   - 41-70: ⚡ Moderate Risk (Warning)
   - 71-100: ⚠️ High Risk (Danger)

2. ANOMALY DETECTION
   Detects:
   - Latency spikes (>2 std deviations)
   - Sudden failures (was up, now down)
   - Error bursts (multiple errors)
   
   Severity:
   - Critical: Immediate action needed
   - High: Investigate soon
   - Medium: Monitor closely

3. AI INSIGHTS
   Generates:
   - Warnings for high risk
   - Info about trends
   - Recommendations
   - Action items
   
   Types:
   - ⚠️ Warning: Needs attention
   - 🚨 Error: Critical issue
   - ℹ️ Info: FYI
   - 💡 Action: What to do

4. SIMILAR INCIDENTS
   Finds:
   - Past incidents with similar keywords
   - Matching root causes
   - Previous fixes
   
   Uses:
   - Jaccard similarity
   - Keyword extraction
   - Text matching
